### 為什麼做這個

沈伯洋的政見裡有一條「文化徑」，把城市的歷史用步道串起來，我超級有共感。之前去波士頓走自由步道（Freedom Trail），一條紅磚線從公園一路畫到邦克山，五月花號、茶黨、保羅・里維爾夜奔，踩在腳下的每一塊磚都有故事，那種「歷史跟現代疊在一起」的感覺一直忘不掉。

回頭看台北，我們腳下其實也有一條線：**漳州人跟泉州人打了一百年的械鬥**。龍山寺、清水祖師廟、霞海城隍廟、士林慈諴宮、芝山岩的隘門，全部都是那段歷史留下來的，而且全部都還在原地。只是沒有人把它畫在地上。所以我先把它畫在 3D 裡。

### 漳泉械鬥到底在打什麼

先講結論：**不是漳州打泉州這麼簡單，台北最慘的那一場（1853 頂下郊拚）其實是泉州人打泉州人。**

來台灣的閩南移民按祖籍分成幾群：泉州府的三邑人（晉江、南安、惠安）、同安人、安溪人，還有漳州府的人。口音不同、拜的神不同、做生意的對象不同（三邑人和泉州福州做生意叫「頂郊」，同安人和廈門做生意叫「下郊」）。官府很弱，來的人很多是沒田沒老婆的「羅漢腳」，大家只認同鄉。嘉慶皇帝的官員楊廷理講得很白：「漳、泉無業游民愛分氣類，所以易於滋事」。

然後為了搶水、搶地、搶碼頭泊船權，一點火就炸：

| 年 | 發生什麼 | 打到哪裡 |
|---|---|---|
| 1787 | 漳、泉、粵三方在白石湖（內湖）械鬥 | 內湖 |
| 1809 | 漳州人聯合客家人攻和尚洲的泉州人 | 蘆洲 |
| 1851 | 八芝蘭械鬥；林本源家族遷到枋橋築城 | 士林、板橋 |
| **1853** | **頂下郊拚**：三邑人向安溪人「借道」燒掉清水祖師廟，攻進同安人的八甲庄；同安人敗退到大稻埕 | 艋舺 → 大龍峒 → 大稻埕 |
| **1859** | 枋寮街大火引爆；泉州人三千多從艋舺、新莊、和尚洲三路攻枋橋林本源家，港仔嘴、瓦窯、加蚋仔全被燒 | 中和、板橋、萬華 |
| 1859–60 | 漳州人反攻；泉州人把士林舊街燒成平地，漳州人退守芝山岩；1860 漳州人大破新莊 | 士林、新莊 |
| 1860–64 | 士林新街重建：潘永清堅持不蓋在芝山岩山腳，井字街廓＋隘門＋慈諴宮 | 士林 |
| 1884 | 台北城完工，官府坐在艋舺與大稻埕中間 | 城內 |
| 1895 | 日本統治開始，械鬥時代結束 | — |

1853 年那場最有戲：三邑人要打同安人，中間隔著安溪人的清水祖師廟和一片池沼過不去，就逼安溪頭人白隆發把神像請出來、廟燒掉「借道」，說好事後幫你重建。打贏之後毀約，廟十四年後安溪人自己重建。輸的同安人帶著從火場搶出來的霞海城隍神像往北逃，想投靠大龍峒的同鄉，被拒絕，只好轉到大稻埕沿河蓋街。結果艋舺後來河道淤積，船全改停大稻埕，輸的人搬去的地方三十年後變成北台灣最有錢的街，還直航紐約賣烏龍茶。

1859 年那場最慘：七月中和枋寮街一場大火，兩邊互指是對方放的，整個盆地的仇一次引爆。泉州人由滬尾的黃龍安帶頭集合三千多人，三路直攻漳州人的大本營板橋林本源家，一路燒。漳州人反攻，戰火燒到士林，泉州人把士林平原上的漳州街市整個燒掉，倖存的人退上芝山岩，靠隘門和高地擋住。今天芝山岩的西隘門、北隘門還在，山上的「同歸所」埋的是歷次械鬥不分漳泉的無主屍骨。

### 同一年的西方世界

這是我最想做的部分。把台北的年份對到我們熟的西方事件：

- **1853 頂下郊拚**：同一年 7 月培里的黑船開進江戶灣；同一個夏天紐約的廚師發明了洋芋片；10 月克里米亞戰爭開打。
- **1859 枋寮大火**：同一年大笨鐘第一次報時、美國鑽出第一口油井、達爾文出版《物種起源》、狄更斯寫下「那是最好的時代，也是最壞的時代」。
- **1860 士林舊街全毀**：林肯當選，隔年美國人也打起來了，打了四年。
- **1863 士林新街畫棋盤格**：倫敦開了全世界第一條地鐵。
- **1884 台北城完工**：全世界在華盛頓決定格林威治是時間的零點；自由女神在巴黎組裝完成。
- **1895 械鬥結束**：盧米埃兄弟放了第一場電影，倫琴發現 X 光。

全部細節都在 3D 裡的每一站。

### 1895 之後：故事沒有停

械鬥結束不是台北打架史的結束，只是換了對象。後半段 16 站我挑的是**都發生在同一片幾平方公里裡**的事：

| 年 | 台北 | 同一年西方 |
|---|---|---|
| 1900–04 | 日本人拆台北城牆改三線道 | 萊特兄弟飛起來 |
| 1921 | 台灣文化協會在大稻埕靜修女學校成立 | 美國女性拿到投票權（1920） |
| 1932–35 | 菊元百貨、流籠、台灣博覽會 | 大富翁上市 |
| 1945 | 5/31 台北大空襲；10/25 日本在公會堂投降 | 10/24 聯合國成立 |
| **1947** | **二二八**：天馬茶房 → 專賣局 → 行政長官公署開槍 | 《安妮日記》出版 |
| 1949 | 四六事件、戒嚴、國民政府遷台北 | 《一九八四》出版 |
| 1950s | 白色恐怖：青島東路軍法處 → 馬場町刑場 | 麥卡錫「我手上有一份名單」 |
| 1961–71 | 中華商場、加工出口、退出聯合國 | 登月；Intel 4004 |
| 1979–81 | 林宅血案、陳文成 | 波蘭團結工聯 |
| 1986–87 | 圓山組黨；解嚴 | 雷根「拆掉這堵牆」 |
| 1989–90 | 鄭南榕自焚；**野百合**在中正紀念堂廣場 | 柏林圍牆倒下 |
| 1996 | 第一次民選總統；第一條捷運 | 桃莉羊 |
| 2000–04 | 政黨輪替；台北 101 | Facebook 上線 |
| **2014** | **太陽花**佔領立法院 24 天 | 基輔獨立廣場；冰桶挑戰 |

最有感的是**青島東路這一條街**：1950 年代是軍法處押政治犯去馬場町的起點，2014 年是太陽花的街，2019 年是四萬人淋雨等同婚三讀的街，2024 年青鳥又回來。同一條街，七十年。地圖上你會看到它就在清代台北城東門外一點點的地方，離 1853 年燒祖師廟的艋舺走路 25 分鐘。

### 城市怎麼長大：地圖會跟著年份長建築

這一版加了「開發進程」：拖年表的時候，地形上會慢慢出現灰色的街廓與一塊塊城市方塊（哪一年起哪一圈變成市區，是照都市計畫與人口資料概略畫的），鐵路、捷運、高速公路沿線會有小火車和小車在跑，指標性建築在落成那一年長出來，拆掉的那一年消失。每一站故事卡下面有一排「🏗 這一站地圖上長出來的」，點名字會飛過去。

| 年 | 長出來（或拆掉） | 為什麼算指標 |
|---|---|---|
| 1884 | 台北城（1904 拆） | 三市街：艋舺、大稻埕、城內 |
| 1891 | 大稻埕火車票房、清代鐵路、台北橋（木橋） | 台灣第一條鐵路，站設在最有錢的大稻埕 |
| 1901 | 台北驛（今台北車站）、縱貫線改線、淡水線 | 四代車站同一個位置至今 |
| 1908–15 | 西門紅樓、新公園＋博物館 | 城牆拆掉後西門外長出娛樂街；公園後來是二二八放送局 |
| 1919–20 | 總督府；台北設市（約 17 萬人） | 城內變成殖民權力中心 |
| 1925／1933 | 台北橋鐵橋、明治橋 | 「鐵橋夕照」台北八景；參拜台灣神社的軸線 |
| 1932–39 | 菊元百貨、公會堂、松山飛行場、松山菸廠；都市計畫 60 萬人 | 摩登台北，市區往東門外、松山擴 |
| 1949–61 | 眷村、三重／中永和擠滿人；中華商場（1992 拆） | 外省移民，人口從 33 萬到 100 萬 |
| 1968–78 | 升格直轄市併入士林北投內湖南港；國父紀念館、中山高 | 人口破 180 萬，東區開始長 |
| 1986–94 | 信義計畫區、世貿、市政府東遷、大安森林公園 | 中心從河邊走到東邊；人口 272 萬高點（1990） |
| 1996–99 | 捷運木柵線、淡水線（淡水線鐵路 1988 停駛）、板南線 | 城市的距離改用「幾站」算 |
| 2002–05 | 台北 101、內湖科技園區、板橋新站特區、小巨蛋 | 工作往內科、住往新北 |
| 2022–23 | 台北表演藝術中心、大巨蛋 | 皮蛋豆腐蓋在士林新街旁，巨蛋蓋在菸廠旁 |

市區範圍與人口都是概數（台北市 1990 年 272 萬是歷史高點，之後往新北流），街廓的位置是示意不是地籍圖。

### 技術

跟上一篇[台北未來島](/yutingblog/diary/2026-10-23)同一套 three.js 手法，但這次是真的地圖：地形是一張 PlaneGeometry，用幾座高斯山（大屯山、觀音山、林口台地、南港山、新店丘陵）加 Simplex 噪聲堆出盆地，四條河照折線往下挖到水面以下；聚落按經緯度換算到世界座標，小房子屋頂顏色＝族群。每一站的 attacks / burned / defend / migrate / rally 寫在 `data.js`，引擎自己畫弧線、生小人、點火、圍人群舉牌子。日治以後的地點用 `modern: true` 畫成水泥方塊，總督府、中正紀念堂、101 各有專屬小模型。沒有任何模型檔。市區擴張是把地形頂點依 `URBAN` 色塊的年份重新上色，城市方塊是一張依年份排序的 InstancedMesh 改 `count`，鐵路／捷運／高速公路是 `LINES` 折線貼地拉成管子，車站、橋、博物館、機場、菸廠、國父紀念館、公園、小巨蛋、大巨蛋、北藝中心各有一個 `landmark` 小模型。
